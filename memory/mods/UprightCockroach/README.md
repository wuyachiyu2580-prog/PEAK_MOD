# UprightCockroach

PEAK 的直立蟑螂客户端视觉替换 MOD，目标是让安装 MOD 的玩家在本地看到自己和其他玩家都变成直立蟑螂。

当前阶段：2026-10-14 用户已确认使用本地 FBX、保留四臂、去掉麦克风和草丛。FBX 无骨架/蒙皮，已生成去场景道具的 24 网格/91,600 三角形转换资源，加入 Scout 驱动骨骼、额外两臂骨骼和触须骨链，并嵌入 8 张实际使用贴图。候选 DLL 已通过 47 项资源/配置检查和离线姿态压力检查；游戏内验收未完成。

接手时先读 `RECENT.md`、`DECISIONS.md`、`FILES.md` 和 `temp/current.md`。
