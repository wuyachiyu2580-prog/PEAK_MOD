# UprightCockroach Decisions

## 已确认边界

- 只做直立蟑螂；不做六足趴地或爬行角色。
- 只改客户端视觉，不改变角色移动、碰撞、状态、网络同步、Photon 对象和游戏规则。
- 不把蟑螂伪装成游戏的 Skeleton/Chicken/Mushroom 状态；这些状态仍由原游戏逻辑控制。
- MVP 隐藏 `CustomizationRefs.AllRenderers` 对应的人体、衣物和帽子，显示蟑螂本体；背包、手中物品和交互可视对象保留。
- 大厅 `PlayerCustomizationDummy` 是否替换暂列后续项，不阻塞关卡内 MVP。
- MVP 先使用运行时 primitive 外壳验证挂接时序和可见性；最终版本再换成绑定 Scout 骨骼的正式网格，避免在没有素材时阻塞插件工程。
- MVP 只压住 `CustomizationRefs.AllRenderers`；背包、手中物品和其他角色交互可视对象不属于蟑螂外观替换范围。
- 第一人称显示双臂/手、触须、翅膀和下腹部，隐藏头部/眼睛/胸部/脚，优先保证可操作视野。

## 模型要求

- 2026-10-14：用户在初筛后选择 Cockroach alien，随后放入本地 FBX。检查显示 FBX 是不同的四臂卡通造型；用户已确认使用本地 FBX、保留四臂、去麦克风和草丛；工作转换资源也去除场景地面。
- 本地 FBX 原文件不变。任何去麦克风、草、地面、改双臂等操作只在确认后的工作副本上做；双足直立不意味着必须删除额外手臂。
- 本地文件的许可未确认，不能直接继承另一作品的 CC BY 标签。
- 触须挂点/局部坐标/旋转与尺寸须可配置；正式模型须保留可调触须骨链或专门附属骨骼。
- 不用预览网格代替官方下载，不把动画数等同骨架证据，不把编译成功等同视觉验收。

- 必须是直立双足比例，能适配 PEAK Scout 的人形动画。
- 首选直接绑定 PEAK 人形骨骼；独立骨架必须提供稳定的骨骼名/父子关系和运行时映射方案。
- 触须、翅膀、腹部等额外部件可以是同一 SkinnedMeshRenderer 的骨骼权重，也可以是挂在头部/躯干的附属 Renderer。
- 需要第三人称 Renderer；本地第一人称若使用同一模型，必须验证头部、触须和腹部不会挡相机。

## 当前风险

- 已提供本地 FBX，但无骨架/蒙皮且是摆姿；需造型确认、重置姿态和新绑定，尚未游戏导入。
- 2.6.b 的关键字段、方法和运行时对象已核对；正式模型接入仍需在同一版本实机验证。
- 人类外观可能被换装、骷髅化、鸡化、蘑菇化、石化和复活流程重新启用，替换组件需要处理这些生命周期。

- 2026-10-14 23:11 用户最终确认：使用这份 FBX，保留四臂，去掉麦克风和草丛。此确认取代此前等待选择状态。角色资源排除场景地面，原 FBX 不变。
