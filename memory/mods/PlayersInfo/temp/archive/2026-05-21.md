## 2026-05-21 Config Review Fixes

- Reviewed PlayersInfo against current code and found real behavior gaps: `EnableStaminaBar` was bound and documented but never read; `Anchor` / `OffsetX` / `OffsetY` were bound but not applied; `RetainOnLossDelay` could temporarily exceed `MaxNearbyCount`; `TeammateBarsCoordinator` did not detach from `TeamRosterTracker.OnRosterChanged` on destroy.
- Fixed config behavior: config sections are now merged into `Display` and `Advanced`. Old `General` / `Features` / `Layout` / `Nearby` / `Diagnostics` entries are read as legacy defaults and removed/saved during startup migration. `Advanced.DebugLogging` replaces old `Diagnostics.DebugLogging`.
- `EnableStaminaBar=false` now hides teammate bars via `TeammateBarsCoordinator.RefreshNearby()` without disabling local stamina value overlay. `Enabled=false` still disables all PlayersInfo HUD features.
- `Anchor` / `OffsetX` / `OffsetY` now apply in `TeammateBarsCoordinator.ApplyConfiguredAnchor()` each refresh/init, so runtime config edits move the HUD without full rebuild.
- `RetainOnLossDelay` now stores the last visible `Character` snapshot while visible and refuses to append retained entries once `s_visibleScratch.Count >= maxN`, so retention does not exceed `MaxNearbyCount`. Coordinator `OnDestroy` unsubscribes from tracker events.
- Added optional `Helpers/ModConfigLocalization.cs`, modeled after LSN but scoped to PlayersInfo. If PEAKLib.ModConfig is installed, it patches setting display names and UI text to localize plugin name, sections, keys, enum values, and descriptions when game language is Chinese. If ModConfig is absent, it returns silently and PlayersInfo still works.
