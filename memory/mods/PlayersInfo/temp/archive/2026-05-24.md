# 2026-05-24 PlayersInfo 临时记忆

## 队友临时体力数字被裁切

- 用户反馈：上次 PlayersInfo 修复后 HUD 像是向左移了，看不全别人临时体力值，只能看到个位数。
- 定位：`TeammateBarsCoordinator.CreateBar()` 中队友临时体力数字 `PI_MateExtraValue` 之前固定用 `AddSideText(driver.fullBar, ..., false, ...)`，也就是贴在 `fullBar` 左端外侧。默认 `Anchor=TopLeft` 时该文本向屏幕左侧扩展，前面的 `+`、十位/百位容易被屏幕边缘或父容器裁掉，只剩右侧个位数。
- 修复：
  - 新增 `ShouldPlaceExtraTextOnRight()`：`TopLeft` / `BottomLeft` 时把临时体力数字放到体力条右侧；`TopRight` / `BottomRight` 时放到左侧。
  - 新增 `ConfigureSideText()` 统一配置侧边文本 RectTransform，宽度从 `90x22` 扩到 `120x24`。
  - 新增 `SyncExtraTextPlacement()`，在 `RefreshNearby()` 里同步已有池对象的位置；运行时改 HUD 锚点也能切换到安全侧，不需要等重建。
  - `AddSideText()` 设置 `tmp.overflowMode = TextOverflowModes.Overflow`，降低 TMP 自身裁切导致前缀/高位丢失的概率。
  - `TeammateBarDriver` 相关注释从“左端外侧”更新为“安全侧外侧”。
- 变更文件：
  - `MOD开发/PlayersInfo/PlayersInfo/MonoBehaviours/TeammateBarsCoordinator.cs`
  - `MOD开发/PlayersInfo/PlayersInfo/MonoBehaviours/TeammateBarDriver.cs`
