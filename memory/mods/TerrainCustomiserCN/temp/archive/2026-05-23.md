# TerrainCustomiserCN 临时记忆 - 2026-05-23

## 本轮收口事实

- 用户要求将原版 TerrainCustomiser 的 UI 更换为中文，做成新 MOD `TerrainCustomiserCN`，并尽可能保持功能不变，让 TerrainCustomiserCN 和 TerrainCustomiser 共用地图数据、能交叉游玩。
- 用户明确要求不要以当前可用的原版 `TerrainCustomiser.dll` 为基底；项目实际以反编译源码整理重建。
- 当前 `TerrainCustomiserCN` 是 2026-05-23 新建的中文 UI 版项目；不要和 memory 中 2026-05-12 的旧 `TerrainCustomiserCN -> DreamyAscent` 改名历史混淆。
- 原版至少有两个前置：`PhotonCustomPropsUtils` 和 `UBImGui`，本地目录在 r2modman terrain profile 的 `BepInEx\plugins` 下。
- 原版反编译参考目录是 `引用参考代码\反编译\BepInEx\plugins\TerrainCustomiser`，原版 `BepInPlugin` 版本为 `0.3.0`。

## 关键兼容判断

- 主客机交叉兼容依赖三件事：原版网络管理器 ID `com.snosz.terraincustomiser` 不变；房间/玩家属性键 `mapData`、`propViews`、`playerInfo`、`TC_inCustomMap` 不变；Sirenix 序列化保存原版 `TerrainCustomiser.*` 类型名。
- CN 版声明 `BepInIncompatibility("com.snosz.terraincustomiser")`，避免同一客户端同时加载中英文两个版本。
- 地图保存路径优先使用原版 `Snosz-TerrainCustomiser\Map Saves`，CN 版目录仅作为候选兜底。
- README 已写明 `TerrainCustomiserCN 0.1.0` 对应原版 `TerrainCustomiser 0.3.0`；后续每次更新都要更新该对应关系。

## 翻译和 Collector

- 主翻译表在 `UI\DisplayNameTranslator.cs`，覆盖 UI、字段、类型、枚举和动态层级/资源名。
- 最新漏项 TSV 曾出现 `CULLER`、`Edges`、`Eggs`、`Mid`、`Middle`，已补为 `剔除器`、`边缘`、`蛋`、`中`、`中间`。
- Collector 只保留 `TerrainCustomiserCN_missing_translations.tsv`，不再生成 `TerrainCustomiserCN_game_zh_en.tsv`。
- Collector 会随发布包上传，方便玩家通过 QQ 群反馈漏译；当前 README 中 QQ 群为 `1093172647`。

## 风险和下一步

- 第四关原版相关 BUG：改动地形可能不生效，等待原作者更新；CN 版不要自行修原版地形生成逻辑，除非用户明确转为功能修复任务。
- 仍可能有零星漏译。后续玩家反馈 TSV 后，优先补 `DisplayNameTranslator.cs` 精确项，再构建、清空 TSV 表头、重打发布包。
- 每次补翻译后检查 UI 是否变形；只有 `C`、`D` 这类单字母显示项按用户要求保持单字，普通英文单词不要强行缩短。
