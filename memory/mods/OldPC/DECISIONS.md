# OldPC Decisions

## 功能边界

- OldPC 只做本地视觉效果，不改变游戏业务、网络状态、房间属性或场景对象。
- 望远镜模式必须恢复进入该模式前捕获的本地设置；退出望远镜模式后回到 OldPC 配置，而不是永久修改玩家的全局画质偏好。
- `General.TelescopeToggleKey` 默认值为 `F8`，不把热键写死在逻辑中。
- 旧电脑模式默认开启，CRT 屏幕效果单独由 `Retro.ScreenEffects` 控制。

## 当前风险

- 尚未通过构建和实机验证，不能把 README 中的视觉行为描述当作已验收结论。
- 后续若接入画质或渲染管线的新字段，必须继续确认所有修改都只作用于本地客户端，并补充退出/场景切换时的恢复验证。
