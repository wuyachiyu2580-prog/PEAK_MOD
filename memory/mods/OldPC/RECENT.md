# OldPC Recent

更新时间：2026-08-31

## 0.0.1 当前状态

- 已建立 `MOD开发/OldPC` 工程，版本为 `0.0.1` / `0.0.1.0`，目标框架为 `net4.7.2`。
- 默认启用本地旧电脑画面模式，包含渲染比例、阴影距离、LOD、纹理 mip、像素光、雾距离、近处雾效和 CRT 风格覆盖层配置。
- 默认使用 `F8` 切换望远镜清晰模式；该模式暂时恢复已捕获的本地渲染设置、提高地形可见度并缩小视野角，再次按键恢复旧电脑效果。
- 只修改本地相机、渲染管线、质量、shader、雾色和屏幕覆盖层状态，不发送 RPC、不修改房间属性、不生成对象，主机不需要安装。
- 当前尚未记录 Release 构建、profile DLL、发行包或游戏内验证结果。
