# WhereIsThing Plan

更新时间：2026-08-14

## 阶段 1：资料和数据边界（已完成）

- 以 PEAK 2.1.a `ItemDatabase.itemLookup` 动态枚举可选物品。
- 核对 `ItemState`、`Item.data`、`BackpackData.itemSlots`、`ItemSlot.prefab` 和 `LocalizedText`。
- 形成特殊物品、食物、神秘物品、储存/背包、移动/攀爬、照明/导航、战斗、生物、其他的类别初稿。

## 阶段 2：基础可运行版（已完成）

- 接入 BepInEx 配置、`C` 扫描和 `Alt+C` 选择窗口。
- 实现地面、手持、落地背包内容的位置标签。
- 实现常驻/计时显示、语言选择、搜索、类别筛选、批量选择和配置持久化。
- 使用游戏 TMP 字体和 Overlay Canvas，Release 构建保持 0 warnings / 0 errors。

## 阶段 2.1：目录和窗口体验修正（已完成）

- 将重名显示项合并为多 itemID 选择组，并显示变体数。
- 接入 `Luggage.ALL_LUGGAGE`，增加地面/手持/背包/行李箱四类范围复选框。
- 将行李箱进一步拆分为复活箱、各场景行李箱、诅咒、小丑和其他类型，并支持按类型持久化选择。
- 将分类细化为医疗、容器、攀爬、移动、照明、导航、武器爆炸物、生物、玩具运动等。
- 将单列列表改为分类内自适应网格，窗口打开期间接管鼠标指针。

## 阶段 3：2.1.a 实机验证（待进行）

- 确认 ItemDatabase 加载时机和完整物品数量。
- 逐类验证地面、手持、背包、拾取、丢弃、场景重载和多人观察结果。
- 确认窗口输入、鼠标恢复、C/Alt+C 冲突、中文字体和窗口滚动。
- 观察大量标签与 0.5 秒补扫的性能、遮挡和屏幕边缘布局。

## 阶段 4：稳定性和体验收口（待进行）

- 根据实机日志修正名称缺失、类别误判、嵌套背包和特殊容器。
- 必要时加入可见范围、分组显示、标签上限或更细的刷新策略。
- 若输入穿透明显，再评估原版 `MenuWindow`/`UIInputHandler` 的兼容接入。

## 阶段 5：发布（待进行）

- 版本升到发布版本，补发行 README、CHANGELOG、manifest、icon 和 zip。
- 在关闭游戏后确认发布 DLL 与 r2modman `2.0.a` profile 中的 DLL 为同一构建产物，并做包内容检查。
