# WhereIsThing Plan

更新时间：2026-09-06

## 当前阶段：0.1.2 / PEAK 2.4.b 实机验收

- 代码实现和静态审计已完成；编译为 `0 warnings / 0 errors`，本阶段不再做发行打包。
- 房主和客户端分别测试：普通/反重力绳索、绳索炮/反重力绳索炮、岩钉、踏板菇、弹力菇、云雾菇、检查点旗、童子军大炮和锁链发射器。
- 验证负例：野生蘑菇不显示错误玩家名；机场、神庙、`PeakSequence`、可破坏锚点绳索和海滩桥不产生玩家放置标签。
- 验证生命周期：目标销毁、切场景、玩家离开和主机迁移后不留错误标签/owner。
- 若帧时间仍有波动，用同地图/同预设记录至少 60 秒 WhySoLaggy 日志，再决定是否调整预算；不得用延长扫描间隔掩盖单帧峰值。
- 分类回归：确认 Jetpack/Rocketpack、Heat Pack、Healing Dart、Healing Puff Shroom、神秘变体、Early Worm、Beehive、Honeycomb、Scorpion、棋子和所有放置工具出现在预期分类，并确认同名变体及场景目标合并没有产生重复入口。

以下阶段 1 至阶段 5 记录早期 2.1.a / 0.1.x 开发历史，不代表当前 2.4.b 验收状态。

## 阶段 1：资料和数据边界（历史，已完成）

- 以 PEAK 2.1.a `ItemDatabase.itemLookup` 动态枚举可选物品。
- 核对 `ItemState`、`Item.data`、`BackpackData.itemSlots`、`ItemSlot.prefab` 和 `LocalizedText`。
- 形成特殊物品、食物、神秘物品、储存/背包、移动/攀爬、照明/导航、战斗、生物、其他的类别初稿。

## 阶段 2：基础可运行版（已完成）

- 接入 BepInEx 配置、`C` 扫描和 `Alt+C` 选择窗口。
- 实现地面、手持、落地背包内容的位置标签。
- 实现常驻/计时显示、语言选择、搜索、类别筛选、批量选择和配置持久化。
- 使用游戏 TMP 字体和 Overlay Canvas，Release 构建保持 0 warnings / 0 errors。

## 阶段 2.1：目录和窗口体验修正（已完成）

- 将重名显示项合并为多 itemID 选择组，并显示变体数。
- 接入 `Luggage.ALL_LUGGAGE`，增加地面/手持/背包/行李箱四类范围复选框。
- 将行李箱进一步拆分为复活箱、各场景行李箱、诅咒、小丑和其他类型，并支持按类型持久化选择。
- 将分类细化为医疗、容器、攀爬、移动、照明、导航、武器爆炸物、生物、玩具运动等。
- 将单列列表改为分类内自适应网格，窗口打开期间接管鼠标指针。
- 增加“仅显示已选”筛选，方便检查和移除当前选择。

## 阶段 2.2：动态危险与地标（已完成，待实机验证）

- 新增独立场景目标目录：森蕈僵尸、甲虫、风滚草、GhostBall。
- 新增地标目录：雾沼五座 GhostFire 钟塔，标签显示已点亮/未点亮状态。
- 场景目标已接入选择持久化、标签名称、扫描入口和销毁/死亡有效性判断，不复用 itemID。
- 待实机确认钟塔标签锚点、动态目标数量、多人端可见性和补扫性能，再决定是否增加标签上限或默认选择状态。

## 阶段 2.3：第一批危险目标（已完成，待实机验证）

- 将场景目标拆分为危险生物、自然危险、机关陷阱和地标四类，避免与普通物品“生物”分类混淆。
- 接入危险生物：蝎子、蜘蛛、蜂群、Scoutmaster；保留既有森蕈僵尸和甲虫。
- 接入自然危险：地刺、蚁狮、捕蝇草、龙卷风、未摘下的晚安莓；保留既有风滚草和 GhostBall。
- 接入机关陷阱：箭矢发射器、移动锯刃、滚刺机关和摆斧机关。
- 本批明确不加入青蛙舌；全局环境状态、易刷屏静态地形和已可作为普通物品追踪的危险物仍不加入。

## 阶段 3：2.1.a 实机验证（历史计划，已被顶部 2.4.b 计划取代）

- 确认 ItemDatabase 加载时机和完整物品数量。

- 确认窗口输入、鼠标恢复、C/Alt+C 冲突、中文字体和窗口滚动。
- 观察大量标签与 0.5 秒补扫的性能、遮挡和屏幕边缘布局。

## 阶段 4：稳定性和体验收口（待进行）
