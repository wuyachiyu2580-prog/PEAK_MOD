## 怎么用

1. 打开工坊和地图编辑器，逐个打开页面、下拉列表、构件网格、材质选择器和悬停说明。每处停留几秒；长列表需要滚动浏览。
2. 疑似漏译会出现彩色边框和 `#编号`。橙色表示匹配原 MOD 内置文案，蓝色表示疑似资源键，黄色表示待人工判断。英文资源显示名可能归为黄色；玩家名称、作者内容也可能被标黄。很小的控件只画边框。
3. `Ctrl + Shift + F12` 导出。也会每 15 秒自动保存有变化的报告，正常退出游戏时再次保存。
4. 本轮采集后，我可以读取报告按编号定位遗漏，不再只依赖截图。不要把“没有框”理解为“这一页已全部翻译”。

| 按键 | 用途 |
| --- | --- |
| Ctrl + F12 | 暂停／恢复扫描和标注 |
| Ctrl + Shift + F12 | 导出当前报告 |
| Ctrl + Alt + F12 | 只开关标注，继续后台记录 |

左下角显示状态和记录数。标注影响查看时，可隐藏标注或暂停。上述快捷键避开了原 MOD 会触发地图导出的 F9/F10/F11。

报告包含编号、实际原文、界面入口、有限的调用栈、场景、中文补丁状态和原 DLL 指纹。同一入口的相同文字合并；记录次数是采样帧数。原文和作者参数保持原样，报告只写本地文件。异常退出可能丢失最后 15 秒尚未写盘的数据。

## 这版的边界

- 所有标注都是“疑似”。匹配内置词也可能恰好与作者名称重名，资源键样式不代表已证明是官方资源。
- 观察实际绘制的工坊 IMGUI，包括加载页转成 IMGUI 的文字；未打开的页面、输入框、原生 TMP／世界文字、其他插件绘制的配置窗口暂不覆盖。
- 每半秒分析新文字，并限制抓栈、缓存、绘制数量和报告容量；超出上限会在状态或报告里注明。超过 16,384 字符的整段文本暂不扫描。页面较密时应多停留一会。
- 不改翻译、资源键、地图存档和联机数据。扫描报告不是完整翻译验收结论。
- 50 项离线检查通过；Unity 实际边框、滚动裁剪、缩放、字体、热键和性能仍待试用确认。

配置文件首次加载后位于 `BepInEx/config/com.wuyachiyu.peakworkshopcnscanner.cfg`。`IgnoreExactText` 可用 `|` 分隔人工确认应保留的完整文本，重启生效。停用整个扫描器可在退出游戏后将它的 DLL 移出 plugins；不会影响已有中文补丁。
