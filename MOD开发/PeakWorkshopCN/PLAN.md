# PeakWorkshopCN 0.1.0 统一修复计划

日期：2026-10-06。目标基线：PeakWorkshop 0.2.0、PEAK 2.6.a。

状态：实施中。全量词表已完成 2,865/2,865 条并生成 4,246 条嵌入译文；资源显示/搜索补丁已继续修正并部署；独立构建 0 警告、0 错误，51 项自动检查通过。Unity 实机、字体、联机和性能矩阵尚未验收；下一轮重启需先确认原 PeakWorkshop 与 PeakWorkshopCN 均加载。

## 目标与边界

新增独立中文补丁 `PeakWorkshopCN`，版本保持 `0.1.0`。覆盖 2,197 个固定缺映射位置、764 个非固定调用、字段 getter、直接语言分支、委托、长说明、资源显示和搜索。作者名称、介绍、对话、聊天、动态参数、玩家导入资产、原资源键、地图格式、配置值、RPC、Bridge 和数字格式保持原样；关闭中文后恢复原 MOD 显示。

官方术语唯一采用：海岸、雨林、森蕈、雪山、方山、火山、熔炉、雾沼、城塞、顶峰、天底、营火。`SHORE=海岸`，`Swamp→GLOOM=雾沼` 已由 2.6.a 场景进度点证实；`Volcano→CALDERA`、`Kiln→THE KILN`、`Nadir→AREA_VOID` 按游戏概念关联。普通名词按上下文处理，不能把英文同词全局替换成游戏术语。

## 实施清单

1. **翻译接入与缓存**：固定文本按准确的 Label、Hint、Short、Name、Desc 字段绑定；动态调用按实际回调来源和跳转边界接入；四种 `Strip<T>` 封闭实例单独注册；模板只解码模板常量并原样插入参数；30 处本地 `tr` 委托仅在 UI 调用端接入；MarkerRef 按中文开关、语言、内容和代次精确失效；修复 Home 语境、ModConfig 声明解析、重复计数和清理异常遮错。
2. **全 MOD 文案**：建图与编辑器、工坊与素材、联机流程、游玩 HUD/加载、配置逐页覆盖。帮助、地形、散布、交互、危险、NPC、队伍、音乐、运动、预设和长说明均纳入，长度不作为跳过理由。固定译文清单保留来源、用途、处理和验证状态。
3. **资源显示与搜索**：目录重建和增量注册时收集官方构件、材质及来源；显示名独立于原键，选择、拖拽、放置、保存和重载仍使用原键。已接入 `Desert_Rock_1→方山岩石 1`、`M_Rock→岩石材质` 等已确认内置键；未知键保留原名并进入待补清单。列表、网格、场景树、属性、散布、材质摘要均在显示边界处理；搜索同时匹配中文和原名。
4. **性能**：启动时解析并缓存精确方法、字段和配置访问器；字体在创建、重建、语言变化时应用；取消每帧全字段扫描和重复字体赋值；TMP/IMGUI 查找失败节流；固定文本按字典、动态文本按调用点分组；资源索引随目录变化增量更新，不缓存无限作者文字或动态数值。

## 兼容与内部能力

内部查询分为术语/文案、资源显示/搜索、刷新协调三类。术语查询优先读取游戏公开简中表，缺键使用已核实回退；资源查询返回中文显示名、原名提示和搜索匹配，但不改变目录键；刷新协调只失效受语言、中文开关、场景、目录和样式变化影响的缓存。补丁只接受核验的原 DLL SHA-256 `CC1ECDE51B0A4F6F36DB54DE2232FB49CAB59CEDE43CBFFEECBC83EC7A868ADC`。

## 验收

- 静态：原 DLL 指纹、Manifest token/签名、字段对应、真实 callback、跳转边界、泛型注册、模板参数和作者内容隔离。
- 参数：空值、单复数、长文本、小数、富文本、双大括号、名称为 Save/Other 等情况；不改变作者参数、配置值或其他 MOD。
- 资源：逐群系和变体检查目录增量；中文/原名命中同一资源；选择、拖拽、保存、重载保留原键；未知官方资源列待补清单。
- 界面：IMGUI/TMP、长说明、1080p/720p、缩放、中文开关至少五轮、重开窗口、跨场景和同帧新建样式。
- 联机：房主、客机及未安装中文补丁的另一端；固定提示中文化，数据和协议兼容。
- 性能：中文关闭、当前版、优化版各热身 30 秒并采样 60 秒，重复三次，记录插件耗时、p50/p95、分配、反射/扫描/字体写入次数和启动耗时。稳定路径不得再次出现反射发现、全字段扫描或重复字体赋值。
